# BalticM Lavalink test

Isolated Lavalink v4 + official youtube-source plugin test.

Render:
- Runtime: Docker
- Root Directory: lavalink-test
- Instance: Free
- Environment: set LAVALINK_PASSWORD to a private random value; do not paste it into chat.

The built-in Lavalink YouTube source is disabled. YouTube playback/search uses lavalink-devs/youtube-source 1.18.2 with multiple InnerTube clients.

This is an isolated test and does not change the existing BalticM music service.
